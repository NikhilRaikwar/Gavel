The Problem
Why Gavel exists
Disputes are slow,
expensive, and unverifiable.
⏳
Time-consuming
Disputes drag on for weeks or months waiting for human arbitrators to review evidence.
💸
Expensive
Legal fees, escrow agents, and arbitration costs eat into the disputed value substantially.
🔒
Off-chain & opaque
Evidence lives in emails and DMs — no verifiable, tamper-proof audit trail exists.

"Traditional escrow requires a human arbiter — someone users must blindly trust."

The Solution
Gavel turns dispute resolution into an on-chain workflow.
No lawyers. No trusted oracle backend.
✓ Smart contract escrow
✓ Somnia AI agents
✓ Auditable validator receipts
✓ Automatic fund release
How it works
01
🔒 Lock Escrow
Both parties deposit equal stakes into the Gavel smart contract on Somnia.
02
📎 Submit Evidence
Each party submits public evidence URLs — GitHub commits, invoices, screenshots.
03
🤖 Agents Deliberate
Somnia AI agents parse, validate, cross-check, and reason over all evidence autonomously.
04
⚖️ Verdict Enforced
Binding verdict triggers automatic fund release. Every step receipted on-chain.

Gavel
The AI Jury
Four agents. One verdict.
The jury deliberates autonomously.
AGENT 01
🔍 Research Agent
Fetches and parses all evidence URLs using Somnia's LLM Parse Website. Extracts factual claims, timestamps, and source credibility scores.
AGENT 02
✅ Validator Agent
Cross-checks extracted claims for consistency and source support. Flags unsupported, duplicated, contradictory, or ambiguous statements.
AGENT 03
⚠️ Skeptic Agent
Stress-tests both sides of the dispute. Surfaces weaknesses, missing evidence, and risk notes without deciding the final outcome.
AGENT 04
⚖️ Judge Agent
Synthesizes all outputs into a final structured verdict: winner, confidence (0–100), and one-sentence reasoning. Determines fund release.
